# 五十音歌词记忆 3.0 改进总方案（草案，未动代码）

目标：一个 App，点「▶ 开始刷」就能自动完成 **学习 + 巩固 + 复习 + 强化**，从五十音一路学到单词和汉字；
平假名和片假名学得一样熟；节奏舒服自然。

---

## 一、架构：只做 APK
1. 不再出网页版成品。电脑上的网页只在开发测试时用。
2. **录音全部改用 Opus 格式、做成单独文件**（不再塞进网页）。实测体积是 MP3 的 24%～47%，人声听不出差别。
   先出一个只含几段录音的**测试 APK**，在你的手机上确认能出声，再全部转换。
3. **学习记录改存到 App 自己的数据库**（IndexedDB），不受浏览器 5 MB 的限制。旧记录第一次打开时自动搬过去。
4. **数据按需加载**：单词库、汉字库、笔顺等放在单独的文件里，用到时才读，App 打开更快。
5. **自动备份**：每周自动导出一份到手机的「下载」文件夹（保留最近 4 份），换手机直接导入，不用再记着手动备份。
6. 最终 APK 约 **80～85 MB**。

## 二、刷题算法（在 2.1 基础上优化）
### 1. 平假名、片假名绑定
- 一个音（か / カ）**两个字都过关才算学会**；五十音表的格子颜色按较弱的一边显示。
- 一边落后时自动多出落后的一边（优先用平片互转、听音选片假名）。
- 片假名整体明显落后时，**暂停放新字**，先在刷题里拉齐（不用再去首页点“片假名专练”）。
- 一边答错时，另一边也提前抽查一次。
- 单词解锁条件改为：清音、浊音的**平假名和片假名都**达到“掌握”。

### 2. 强化训练自动穿插（不用去首页点）
- **易混字小组**：把 シ 认成 ツ 后，接下来几题自动插 2～3 道 シ / ツ 对比（找字、快速判断）。
- **提速小组**：“记得但慢”的字攒到 3 个，穿插几道快速判断。
- **反复忘记的字**：自动换一种记法提示（联想 ②、字源），更早再考。
- **单词 / 汉字同理**：意思相近、读音相近的词，同一个汉字的不同读法，自动做对比题。
- 每次只占几题，夹在正常流程中间。

### 3. 舒服自然的节奏
- **新字分散**：新字的巩固题平均分布在接下来十几题里，不扎堆。
- **难度自动调**：最近 10 题正确率高于 95% → 多放新内容和难一点的考法；低于 70% → 多出熟字和简单考法。保持在 80%～90% 这个最有效、也最舒服的区间。
- **不再弹窗打断**：今日推荐量到了，只在顶部显示一行“今日推荐已完成，继续刷会接着学”，想停就停。
- **每 20 题一句小结**（例如“这组 18/20，片假名进步明显”），不打断。
- 保留：同一个字隔 4 题、平片交替、连错后缓一缓、每 30 分钟休息提醒。

### 4. 开局定级（新）
- 第一次使用（或重置后）可以做一个 3 分钟的**快速定级**：系统抽查各行，你会的直接标熟练（之后照常抽查），不会的从头学。
  适合“平假名大概会、片假名不太会”这种情况，不用从 あ 慢慢学。

### 5. 参数个性化
- 现在只是整体按你的记录调一个倍数。改为：答满约 1000 题后，**在手机上用你自己的答题记录重新拟合 FSRS 参数**（每周一次，几秒钟），复习间隔更贴合你。

## 三、单词 + 汉字
### 1. 单词（已有，补强）
- 新标日 初级 → 中级 → 高级 9117 词，真人录音。
- **歌词例句**：单词在你歌单的歌词里出现过，就显示那一句（带注音、罗马音、配音）。
- **课本短句**：《一人で学べるひらがなカタカナ》里的短句（「私は研修生です」等）作为单词阶段的听力材料。

### 2. 汉字：嵌在单词里学，不单独开一条学习线
- 学到带汉字的新词时，它用到的汉字一起登场：这个词里的读法、和简体字写法的差异、笔顺。
- 每个汉字按**读法**分开记（生＝せい、生＝しょう 各一份）；只有**日文写法和简体不同**的字才单独考写法。
- 新题型：在词里认读汉字、同字不同读、字形辨析（日文写法 vs 简体）、听读音选汉字、笔顺默写（可选）。
- **「汉字」页**（查询和专项复习）：按课程 / 部首浏览；每个字的所有读法及对应例词（真人录音）、和简体的差异、笔顺动画和描红、部首、歌词例句；可以手动标记，可以“汉字专练”。
- 资源：Kanji alive（约 1235 字、读音、意思、部首、1 万多段例词录音，E 盘已有）；KanjiVG 汉字笔顺（**需要下载，约 10～20 MB，下载前告诉你准确文件名和大小**）；新标日例词。

## 七、检查 2.1 发现的问题（3.0 一并修）
1. **记录写满会悄悄丢数据**：保存失败时程序直接忽略、不提示。学完全部单词 + 汉字后记录约 3.9 MB，接近浏览器存储上限 → 改数据库（第一部分已含），并加“保存失败”提醒。
2. **快速判断题有 50% 能蒙对**：蒙对也按“记得”算，会高估熟练度 → 快速判断答对最多算“记得”、不算“很熟”，且只用在已经熟悉的字上。
3. **新单词也让你先“猜意思”**：假名可以先猜读音，但单词意思没法猜，答错还显示红叉 → 新单词改为先展示（词、读音、意思、录音、歌词例句），几题后再考；新字猜错也不显示红叉，只显示“这是新字”。
4. **60 秒冲刺还在用罗马音选项** → 改成听音选字 / 看字选发音的快速版本。
5. **课本听写的结果不进记录** → 听写写错的词，把里面写错的假名记为薄弱。
6. **“一天”从半夜 12 点算** → 改成凌晨 4 点换日（熬夜刷题不会被拆成两天）。
7. **答题日志只留最近 3000 条，而且不够详细** → 数据库里保存完整日志（哪一题、隔了多久、几分、用时），参数个性化需要它。
8. **自己导入的歌词没有卡拉 OK 高亮**（用系统语音朗读）→ 用朗读进度事件做近似的逐字高亮。
9. **汉字数据放进单独文件后，字体裁剪要把这些字也算进去**，否则会显示成系统字体 → 打包脚本一并处理。
10. **署名**：Opus 转码、Kanji alive、KanjiVG 的许可说明要更新。
