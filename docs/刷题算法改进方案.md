## 2. 每样资源怎么用

### 教材音频 → 假名发音的"标准答案"（108 段已全部转写，结构如下）
课本分两大部分：第 1～12 课平假名，第 13～26 课片假名。每课的结构都一样：先念一行假名，再打乱顺序念一遍，然后念几个例词，最后是听写练习。

| 内容 | 在哪几段 | 用法 |
|---|---|---|
| 单个假名：清音、浊音、半浊音 | 002 整表，各课 x-1 / x-3 | 按停顿切开，**全部 71 个换成这位老师的录音**，统一一个声音 |
| 拗音 33 个，以及拗长音（キャー キュー キョー…） | 11-2、11-4 | 拗音全部换成真人录音，拗长音用来做长音练习 |
| 片假名外来语特殊音（ファ フィ フェ フォ、ティ、チェ…） | 25-1～25-3 | 换掉扩展音的合成音 |
| 打乱顺序念的整行（カ キ ク ケ コ キ ケ コ カ ク） | 各课 x-2 第 1 部分 | 做成"跟着课本听一串、点出顺序"的听音题 |
| 课本例词，平假名约 80 个（かお、いぬ、はな、さかな…），片假名约 90 个（ギター、タクシー、カーテン、ホッチキス…） | 各课 x-2 第 2 部分及之后的练习 | 每学完一行，就用这一行的课本例词做读词题和听写题，原声播放 |
| 长音、促音对比（おばさん / おばあさん，かこ / かっこ，きて / きって…） | 9-1、9-2、10-1、10-2 | **听辨对比题全部换成课本原声** |
| 拟声拟态词（ほかほか、ぷかぷか、ぱたぱた…） | 6-7 | 用于浊音、半浊音的听辨 |
| 编号听写（1. 山 2. 夜 3. どれ…）和单元测验（テスト 2～6） | 2-5、4-5、6-8、8-5、11-7、tesuto 等 | 做成**「课本听写」模式**：播放第几题 → 你写出来 → 显示答案自己核对。每学完一组行解锁对应的一套 |
| 短句（私は研修生です、きのうにほんへきました…） | 12-x、26-4、26-5 | 不放进日常刷题。在单词阶段作为可选的听力材料 |
| 声调示范（箸 / 橋）、数字 | akusento、suji | 讲解页加「声调入门」「数字读法」两节，配原声 |

切分时用 large-v3 定位每个词，再按课本固定的顺序对上号。注意：large-v3 会把一些词写成汉字（比如把 かぎ 写成「鍵」），还会在静音处编出"ご視聴ありがとうございました"这类句子，所以**每一段都会和课本顺序交叉核对**，对不上的列出来给你人工确认。

### 新标日单词 → 真实单词例句 + 后续的单词模块
- **假名阶段：真词例句**
  - 1699 个纯假名词，加上所有词的读音，几乎每个假名都能找到 ≥3 个带真人录音的真实单词。只有少数拗音和片假名例外，比如ヒュ、ピョ，这些继续用现有的例词。
  - 讲解页的"常用词"、读词题、听写词题优先用这些词：按新标日课号排，先出初级常见词，显示中文释义，播放真人录音。
  - App 里现有的例词能对上新标日的，录音就换成新标日的。
- **单词阶段：新的「单词」页**
  - 假名整体稳固度达到 80% 后解锁。按新标日课程顺序（初级 1 课 → 48 课 → 中级 → 高级）学单词。
  - 两个方向：看日文说意思、看中文说日文。
  - 用和假名同一套学习 / 巩固 / 复习算法（见第三部分）。
  - 你以前说的"另开一个学汉字的项目"，就此合并成这个 App 的下一阶段，不用另外做。

### 联想记忆图 → 讲解页的"另一种记法"
- 只裁出下半部分（谐音口诀和插图），放在我们自己的图像记忆卡下面，标题叫"联想 ②"。
- 新字第一次出现时，两种记法一起给。以后哪个字老是答错，就提示换一种记法试试。

## 3. 打包方式（因为体积变大必须改）
- 现在所有录音都是转成文字塞进网页的，最多只能装十几 MB。203 MB 的单词录音必须改成 **APK 里的独立音频文件**，网页按文件名去读。
- 新标日原始录音是 22050 Hz。你之前就遇到过这个采样率在手机上**放不出声**的问题，所以全部统一转成 24 kHz 单声道。转完单词录音大约 80～100 MB，**APK 预计 120～150 MB**。
- 电脑网页版：改成"网页 + 一个音频文件夹"，一起拷走就能用。
- GitHub 公开版不包含这三样资源（都有版权），保持现在的样子。

# 二、五十音表自定义状态

在五十音表上可以**手动标记**每个字：**熟练 / 不熟练 / 未学**。

## 怎么操作
- 五十音表右上角加一个「标记」按钮。进入标记模式后点格子，会在「熟练 → 不熟练 → 未学 → 恢复自动」之间切换。
- 点行首的「か行」可以整行一起标；点「清音」等标题可以整段一起标。
- 平假名和片假名可以分开标，也可以一起标。比如平假名标熟练，片假名标不熟练。
- 手动标过的格子右上角有个小图钉，和系统自动判断的状态区分开。

## 每种标记对算法的影响

| 标记 | 效果 |
|---|---|
| **熟练** | 直接当作已经掌握：跳过新字学习，记忆稳定度设为约 30 天。**大约一周后抽查一次**：答对就确认熟练；答错会提示"这个字好像没那么熟"，自动转成不熟练 |
| **不熟练** | 立刻进入重点练习：稳定度降到很低，最近几天会频繁出现，"薄弱字专练"里排在最前面。答对几次以后自然回到正常复习，标记会自动淡化成"系统自动" |
| **未学** | 从学习记录里移出（会先确认），以后按顺序当作新字重新学。还没学到的行，也可以先标成未学，跳过它先学后面的 |
| **恢复自动** | 去掉手动标记，完全由系统按答题记录判断 |

这样适合你的情况：比如平假名大部分已经会了，就整段标熟练，系统主要只练片假名和薄弱字。

# 三、学习 + 巩固 + 复习算法

## 1. 记什么
- 每个字（平假名、片假名分开）只有 **2 份记忆**：**「认」**（看到或听到能认出来）和 **「写」**（能写出来）。单词也是每个词 2 份：看日文知道意思、看中文说出日文。
- 看字读音、听音选字、平片互转、歌词认字、全表点字……这些题型只是**考法**，不再各自单独排队。
- 现在每个字有将近 10 张卡，改完后复习量大约只剩四分之一。

## 2. 三个阶段

### ① 学习（第一次见到这个字，当天）
依据的研究：先猜后学、图文双重编码、少量多次。
- **先猜**：新字先给你四个选项猜一下读音，猜错也没关系，先试一次再学记得更牢。
- **再学**：马上展示我们自己的图像卡、联想 ②、字源、口诀，同时播放教材真人发音，平假名和片假名一起看。
- **立刻测**：几秒后考一次。
- **一次只学一小组**：同一行的 2～3 个字。容易混的字（シ / ツ、ソ / ン、ぬ / め）**不安排在同一天学**，先学好一个，过几天再学另一个，并且学的时候专门做对比练习。

### ② 巩固（当天到第 3 天）
依据的研究：间隔逐渐拉长的回忆、睡眠巩固。
- **当天**：大约 1 分钟、6 分钟、20 分钟后各考一次，每次换一种考法（看字 → 听音 → 平片互转），并且要和其他字混在一起考。
- **第 2 天**：必考一次。睡过一觉还记得，才算真正记住了。
- **第 3～4 天**：再考一次，通过后进入长期复习。
- 巩固期间答错：先连同易混字做一次对比讲解，几题后再考，巩固进度不清零。

### ③ 复习（长期，FSRS 算法）
- 用 **FSRS-5**（Anki 现在的默认算法）。每份记忆记两个数：**稳定度 S**（能记多少天）和**难度 D**。随时算出当前记得的概率 R。
- 等 R 降到**目标记忆率**（默认 90%）附近时再考：快要忘、还没忘，复习效率最高。
- **答对**：S 变大。难记的字涨得慢，容易的字涨得快。
- **答错**：S 缩小，但不清零。比如 20 天降到 4 天左右，当天隔几题再考一次。
- **反复忘记的字**（错 4 次以上）：自动标成"不熟练"，提示换一种记法，并安排和它的易混字做对比练习。
- **提前复习也算数**：到期的题刷完了接着刷，系统会出最快会忘的字，答对照样增加稳定度（比正常到期时涨得少）。所以连续刷 1～3 小时，每一题都有进度。
- 用满 1000 次答题后，可以根据你自己的答题记录**校准算法参数**，算出更适合你的复习间隔。

## 3. 判分：4 档，快慢跟你自己比

| 档位 | 什么情况 |
|---|---|
| 忘了 | 答错，或者先看了讲解 |
| 吃力 | 答对，但比你平时明显慢 |
| 记得 | 正常答对 |
| 很熟 | 答对，而且比你平时明显快 |

- 系统会记住你在每种题型上最近 50 次的反应时间中位数，作为你的"平时速度"。超过约 1.8 倍算吃力，不到 0.6 倍算很熟。
- 蓝牙延迟每次都差不多，会被算进"平时速度"里，自动抵消。
- 吃力也会升级，只是间隔涨得少一点。字不会卡住不动。
- 自己打分的题（默写等），按钮也对应这 4 档。

## 4. 考法怎么挑（难度循序渐进）
- 一个字的记忆越牢，就用越难的考法：
  - 刚学：看字选读音。
  - 熟悉一点：听音选字、平片互转。
  - 掌握后：歌词认字、全表点字、听写真实单词。
- 每次优先出你在这个字上**最近答得最差**的考法。
- **「写」**等「认」的稳定度到 1 天以上才开始考，频率比「认」低。

## 5. 一次刷题怎么安排（推送节奏）
1. **到期复习**：最快会忘的先出。
2. **巩固中的字**：按 1 分钟 / 6 分钟 / 20 分钟的节奏插进来。
3. **新字**：每天有配额（默认 10 个音），大约每 12～15 题插一个新字。不会因为复习积压被卡住，但如果系统预测**明天的复习量会超过上限**（默认 150 题），会自动少放新字。
4. **舒服的节奏**：
   - 同一个字（平假名或片假名）至少隔 4 题才再出现，平假名和片假名交替出。
   - 连错 2 题后，插一道你很熟的字缓一缓。
   - 每 30 分钟提醒休息。
5. **今日目标**写成具体数字："复习 63 题 + 新字 10 个 + 巩固 18 题，约 20 分钟"。完成后可以继续刷。

## 6. 熟练度怎么显示
- 每个字显示"现在记得的把握 R%"和"能记多久 S 天"。
- 五级状态：未学 → 学习中（巩固期）→ 熟悉（S 在 1～7 天）→ 掌握（S 在 7～21 天）→ 稳固（S ≥ 21 天）。手动标记的字显示图钉。
- 五十音表格子按 R 着色：越绿越牢，发黄表示快忘了。
- 统计页新增三张图：未来 7 天每天的复习量预测、平均记忆率的变化曲线、平假名和片假名的掌握对比。

## 7. 旧记录迁移
- 你现在的学习记录全部换算成新的 S 和 D，已经学过的字不会被当成新字重学。
- 答题日志、易混记录、自己写的口诀、导入的歌词，全部保留。

# 五、已确定的决定（2026-11-01）

| 项目 | 决定 |
|---|---|
| APK 体积 | 120～150 MB 可以接受，资源全部放进去 |
| 单词模块 | **这次一起做**。五十音掌握度约 80% 时自动解锁；设置里有「提前开启单词」开关 |
| 每天新假名 | **自适应**：起步 10 个，在约 5～20 个之间按"第二天还记得的比例 + 预计复习压力 + 每天练习时长"调整 |
| 每天新单词 | **自适应**：起步 20 个，规则同上；和假名共用一个每日量，假名学得越多，单词所占比例越大 |
| 每天复习量 | **自适应**：起步 150 题，之后按你最近 7 天实际刷题量的中间水平 |
| 目标记忆率 | **自适应**：起步 90%；累计约 1000 题后按你的记录算出最省时间的值（85%～95%），显示给你，也可以手动固定；同时校准 FSRS 参数 |
| 超过推荐值 | **只提醒，不阻止**。新字/新词：弹提示卡（继续学 / 今天先复习）；复习量：提示一次后照常出题 |
| 版权资源 | 只放进你自己的版本，GitHub 公开版不放 |
| 提交和发布说明 | 不加任何 AI 署名 |
| 工作方式 | 每个阶段做完先报告、给 APK 试用，你确认后再做下一阶段 |
